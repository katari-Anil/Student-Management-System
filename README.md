
# Student Management System

## Description
A simple web-based application developed to manage student information.

## Features
- Home page
- Student registration
- Student records
- Delete student records
- Local storage for saving student information

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Team Members
- Anil - Team Leader and Integration
- Karthik - Home Page
- Harish - Student Registration

## Installation and Execution
1. Clone the GitHub repository.
2. Open the project in Visual Studio Code.
3. Open index.html using Live Server.
4. Navigate to the registration page.
5. Register student information.
6. View registered students.

## Collaboration Workflow
1. Create GitHub Issues.
2. Create feature branches.
3. Develop project features.
4. Commit and push changes.
5. Create Pull Requests.
6. Review and merge approved changes.

To understand how multiple developers collaborate using GitHub
repositories, branches, Issues, Pull Requests, code reviews,
and project documentation.
