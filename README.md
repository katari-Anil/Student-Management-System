## 📌 About the Project

The Student Management System is a simple web-based application
designed to manage student information efficiently.

It provides an easy-to-use interface for registering students,
viewing student records, and deleting student information.

This project demonstrates how multiple developers can collaborate
using GitHub repositories, branches, Issues, Pull Requests,
and code reviews.

---

## ✨ Features

- 🏠 **Home Page** – Welcome page with project information.
- 📝 **Student Registration** – Register student details.
- 👨‍🎓 **Student Records** – View registered student information.
- 🗑️ **Delete Records** – Remove student information.
- 💾 **Local Storage** – Save student data in the browser.
- 📱 **Simple Interface** – Easy navigation between pages.

## 🚀 Installation and Execution

Follow these steps to run the project:

1. Clone the repository.

   ```bash
   git clone https://github.com/katari-Anil/Student-Management-System.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server.

4. Navigate to the Student Registration page.

5. Enter student information and register.

6. Open the Student Records page to view registered students.

7. Delete student records when required.

## 🔄 GitHub Collaboration Workflow

The project follows a team collaboration workflow:

1. Create a shared GitHub repository.
2. Invite team members as collaborators.
3. Create GitHub Issues and assign tasks.
4. Create feature branches for individual tasks.
5. Develop and commit changes.
6. Push feature branches to GitHub.
7. Create Pull Requests.
8. Review the submitted code.
9. Merge approved Pull Requests into the main branch.
10. Update project documentation.
